# Стрелка — PWA-пилот

Демонстрационный веб-пилот сервиса управления импортными поставками из Китая.

## Запуск
Откройте опубликованный HTTPS-адрес в браузере. Установка на устройство необязательна: приложение работает как веб-сайт. В поддерживаемых браузерах можно выбрать «Установить приложение» или «Добавить на экран Домой».

## Публикация через GitHub Pages
1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `pwa-pilot` (после проверки и переноса в основную ветку — `main`) и папку `/ (root)`.
4. Сохраните настройки и дождитесь успешной публикации в **Actions**.

Если GitHub Pages уже настроен на `main`, после слияния изменений дополнительная настройка источника не потребуется.

## Состав
- `index.html` — интерфейс пилота.
- `manifest.webmanifest` — метаданные устанавливаемого веб-приложения.
- `service-worker.js` — кэширование оболочки для повторного запуска и базовой офлайн-доступности.
- `icons/strelka.svg` — иконка приложения.

## Важное ограничение демо
Данные в интерфейсе демонстрационные. Действия в интерфейсе не отправляются в реальные ERP, 1С или системы операторов перевозки. Указанные интеграции являются примерами, а не действующими подключениями.
